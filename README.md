# Learning Git (Day 1)

Practice repository from my first day learning Git at Devsloop. It exists to try out the basic workflow: creating files, committing and pushing to GitHub, including pushing over SSH.

## Contents

| File | Purpose |
|---|---|
| `index.html`, `another.html` | Simple HTML pages used to practise adding and editing files |
| `new.php` | Empty PHP file for practice commits |
| `test.rb` | Empty Ruby file for practice commits |
| `testssh.txt` | Empty file used to test pushing over SSH |

## Commands practised

```
git init
git add .
git commit -m "message"
git remote add origin <url>
git push -u origin main
```

Nothing here is meant to be run or deployed. It is kept as a record of where I started.
